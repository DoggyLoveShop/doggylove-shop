Catálogo

Cómo está construida esta página

Un proyecto front-end sin dependencias: HTML semántico, CSS con variables y JavaScript modular. Todo el catálogo sale de un arreglo de datos, así que agregar un producto no requiere tocar el HTML.

Stack y decisiones

HTML5Etiquetas semánticas (header, main, section, aside) y atributos ARIA para lectores de pantalla.
CSS3Design tokens con variables, Grid, Flexbox y diseño responsive con clamp() y media queries.
JavaScriptRenderizado desde datos, delegación de eventos, filtros combinados y estado del carrito.
PersistencialocalStorage guarda el carrito aunque se cierre la pestaña.
ValidaciónFormulario validado en el cliente con mensajes de error accesibles.
HerramientasVisual Studio Code, Live Server y Git para control de versiones.
